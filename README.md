# BackDoor

A cybersecurity monitoring dashboard for detecting suspicious login activity, brute-force attempts, security alerts, and account threats.

## Features

- User login and authentication
- Failed login attempt tracking
- Brute-force attempt detection
- Automatic account blocking
- Suspicious IP tracking
- Security alerts
- Activity monitoring dashboard

## Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Purpose

BackDoor was developed as a practical cybersecurity project to explore authentication security, login monitoring, brute-force detection, database management, and security dashboards.

## Running the Project



The project runs locally using Python, Flask, and MySQL.

Built as a learning project to develop practical cybersecurity and software development skills.
